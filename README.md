# Huffman Encoder & Decoder

A simple web-based project that demonstrates Huffman Coding for encoding and decoding messages.

## Live Demo

https://neha-khan02.github.io/Huffman-Encoder-Decoder/

## Features

* Enter a message
* Calculate character frequency
* Generate Huffman Tree
* Generate binary codes
* Encode message into binary
* Copy encoded binary
* Separate Sender and Receiver pages
* Paste and receive binary message
* Decode binary message
* Display the original message

## Technologies Used

* HTML
* CSS
* JavaScript
* Huffman Coding Algorithm

## Project Structure

```text
Huffman-Encoder-Decoder/
├── index.html
├── receiver.html
├── style.css
├── script.js
└── README.md
```

## How It Works

The Sender enters a message and encodes it using Huffman Coding. The generated binary message can then be copied and sent to the Receiver.

The Receiver pastes the binary message, receives it, and decodes it back into the original message.
